## voxmesh

로컬 대사팩을 기반으로 음성/영상을 조합하는 웹 밈 생성기. 서버 없이 브라우저에서 바로 실행되고, 텍스트 입력만으로 영상과 오디오를 생성.

-----
텍스트 입력 후 자막 on/off 기능과 내보내기 기능 등등 여러 단순한 기능들이 있습니다.
> [!NOTE]
> $`\color{blue}\text{음성팩을 사이트에 올려 시작하세요}`$
> 
> 디스코드 서버를 들어가서 공식 음성팩을 찾아보세요. 굳이 디코 서버에 참여하지 않아도 괜찮아요. 아무나 볼 수 있는 상태입니다.

> [!NOTE]
> $`\color{red}\text{음성팩을 어떻게 올려요?}`$
>
> 폴더 자체를 사이트에 올리면 돼요.

> [!NOTE]
>
> $`\color{green}\text{왜 음성팩을 사용자가 직접 다운받아 올려야 하나요?}`$
>
> 음성팩을 올려놓을 서버가 없어요. 사이트의 영상들은 모두 로컬로 처리되니, 음성팩을 지워버리면 다시 다운로드 해야 돼요.


------
> [!NOTE]
> $`\color{blue}\text{내보내기를 누르면 확장자가 .mp4가 아니에요}`$
> 
> 크롬(Chrome)이나 엣지(Edge) 브라우저에 내장된 MediaRecorder는 H.264(MP4) 라이선스 비용 문제 때문에 **태생적으로 WebM(VP8/VP9 코덱) 녹화만 지원**합니다.

> [!TIP]
> $`\color{green}\text{해결 방법}`$
> >
> WebM 파일을 MP4로 변환해야 하는 경우, 인터넷에서 WebM 파일을 MP4로 변환 사이트를 검색해 사용하거나,
> 
> 다른 사람이 만든 [browservc](https://github.com/rahuld109/browservc) 저장소를 참고하시기 바랍니다.
